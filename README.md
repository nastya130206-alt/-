# Документация: API‑тесты (Python + pytest + requests)

## Назначение
Набор функциональных тестов для проверки API YouGile:
- Получение списка проектов.
- Валидация полей при создании проекта.
- Получение проекта по ID.
- Получение пользователя по ID.
- Обработка несуществующих ресурсов (404).

## Технологии и синтаксис
- **Python** — основной язык написания тестов.
- **pytest** — фреймворк для запуска и структурирования тестов.
- **requests** — HTTP‑клиент для отправки запросов.
- **JSON** — формат данных для валидации ответов.
- **PEP 8** — стиль написания кода.
- **Docstrings** — документация методов и функций.

## Предварительные требования
- Python 3.9+
- Установленные зависимости (см. `requirements.txt`)
- Доступ к тестовому стенду YouGile
- Переменные окружения:
  - `BASE_URL` — базовый URL API (например, `https://api.yougile.com`)
  - `AUTH_TOKEN` — токен авторизации (Bearer)

## Установка зависимостей
```bash
pip install -r requirements.txt
